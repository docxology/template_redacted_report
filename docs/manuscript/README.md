# Redacted report manuscript

The shared renderer reads these sections in order.

1. [Abstract](00_abstract.md)
2. [Introduction and methods](01_methods.md)
3. [Results and discussion](02_results.md)

[Configuration](config.yaml) defines the report metadata and analysis order.
The [preamble](preamble.md) and [bibliography](references.bib) support rendering.
The [render guide](../rendering.md) explains how to regenerate the figures and
produce the PDF, HTML, and slides.
